# 产品选择与可用性门槛

本表用于实际运行前筛查，不预设四种方案都可安装或公平比较。记录探测日期、机器/OS、CPU、内存、磁盘、网络与所需权限；依官方指引核对依赖。仅从官方来源取得版本，记录安装包/镜像摘要和配置；不自动安装、不申请特权、不连接付费服务。无法满足时记 `blocked`/`not_available` 和原因，而非 0 分。

| 方案 | 角色及需验证的能力 | 安装与运行条件 | 参照 |
|---|---|---|---|
| DocFetcher | 本地关键词/全文检索基线，不自称语义检索或生成；核实中文分词、PDF 文本层、结果及原文定位 | 目标机支持的桌面系统及图形界面；官方列 Windows 7 SP1+ 64 位、Linux GTK3 64 位、macOS 11+，1.1.26 起无需另装 Java；具体版本以官网下载页和实际机器为准。需本地文档索引 | [下载及要求](https://docfetcher.sourceforge.io/download/)、[功能与格式](https://docfetcher.sourceforge.io/) |
| AnythingLLM | 本地 RAG 产品候选；验证可导入文档、导出或观察检索证据；生成另测 | Desktop 支持 Mac/Windows/Linux；Docker 为另一部署方式。选择一条已获授权路线，核对系统、磁盘、模型与网络；仅使用已许可的本地模型及组件，不假设 API/付费账号 | [安装概览](https://docs.anythingllm.com/installation-desktop/overview)、[本地 Docker](https://docs.anythingllm.com/installation-docker/local-docker) |
| Open WebUI 本地混合 | 本地混合检索候选；验证实际版本的 BM25、向量、重排与证据输出，记录启用情况，不把未启用的功能当已测 | 需要可用的本地运行环境、嵌入模型及可选本地重排/生成模型；实际依赖和安装按官方文档与资源检查，不假定联网下载或 GPU 可用 | [RAG/混合检索](https://docs.openwebui.com/features/chat-conversations/rag/)、[快速开始](https://docs.openwebui.com/getting-started/quick-start/) |
| HCS | 本仓库待评系统；确定提交、模型、查询接口、语料范围、可见证据与运行方式 | 先读 仓库根目录 `README.md` 和锁定配置，检查 Python、模型文件和本地算力；依赖未就绪则记录阻塞，不臆测云端服务或项目能力 | 本地 仓库根目录 `README.md`、仓库根目录 `docs/` |

冻结：在首道正式测试前写入 `run_manifest.json`，包括产品版本、安装来源/哈希或容器 digest、HCS commit、OS/硬件、文档哈希、模型名称和 revision/hash、切分/索引参数、检索 top-k/阈值、提示词及生成参数、资源、网络模式、时间起止。不得用 `latest` 作最终版本标识；改版本或调参须建立新 run，不覆盖首轮。

评价用途：先比较可观察的检索证据覆盖、耗时与失误，再在同样生成模型和证据预算可行时单列生成结果。DocFetcher 原生非生成工具，生成列记 N/A；不得把检索产品缺乏生成能力记为答错。比较无法统一的输入、输出或截断时要明确披露，只做对应范围内的比较，不预先宣布赢家。
