## 一、修订范围

本轮只修订资料清单，逐份记录：

- 实际使用的正文来源 URL；
- 发布单位；
- 版本（令号/文号及修正说明）；
- 可确认的施行日期；无法由快照确认的写“待核”；
- 镜像来源、PDF 文本提取、来源替换和附件缺失情况。

未修改 `data/questions.jsonl`、`data/gold_ai_draft.jsonl`、`data/gold_normalized_draft.jsonl`；未安装产品；未运行检索或测试。

## 二、字段说明

修订版保留原清单的 `id`、`title`、`version`、`category`、`articles`、`url`，新增：

| 字段 | 含义 |
|---|---|
| `publisher` | 法规发布机关 |
| `publisher_note` | 联合公布/同意情况（仅第 07 份） |
| `effective_date` | 可确认的施行日期；无法确认写“待核” |
| `effective_note` | 日期依据或“待核”原因 |
| `effective_raw` | 原清单 `effective` 的原始表述 |
| `source_url` | 实际使用的正文来源 URL |
| `source_channel` | `official_webpage`、`mirror_webpage`、`official_pdf_text_extracted`、`replaced_webpage`、`reposted_webpage` |
| `source_note` | 镜像、PDF 提取或来源替换说明 |
| `snapshot` | 快照文件、正文行号范围、条款范围、SHA-256 |
| `attachments` | 附件状态、缺失清单和说明 |
