# HCS vs DocFetcher 小规模任务计时试跑：预注册协议

冻结时间：2026-11-03T15:26:21+08:00
题目与参考依据：`reports/timing_trial_questions.json`（本文件与题面文件在本轮执行前写入）

## 1. 目的与边界

目的：真实走完两个工具的完整查找流程，暴露计时与操作上的问题。

边界：**本轮不证明任何产品提效**。样本小（4 题）、单一操作者、非盲、同机同人，
结论只能用于发现流程问题，不能用于效率或效果结论。

## 2. 资料锁定

  SHA-256 `4a815f2cecd083c2…`
- B：《建设工程质量管理条例》（`revised_2019_04_23`），`work/raw/B_copy_cas.pdf`，
  SHA-256 `651fa2536cc3c86f…`
- DocFetcher 使用同一组文件的副本 `work/tools/docfetcher/test_corpus/`，哈希与上面一致（执行前已核对）。
- HCS 使用 A/B 官方 HTML 正文，PDF 仅作页锚点；两边解析条件不同，这一点在结果中保留，不宣称等价。

## 3. 工具设置

| 项 | HCS | DocFetcher |
| --- | --- | --- |
| 检索方式 | `hybrid_top5`，自动补证关闭 | 既有中文索引 `hcstest`（Ansj 分词），本轮不重建 |
| 初始化 | 服务启动 `init_ms` 单独记录 | 应用启动耗时单独记录；建索引时间沿用既有索引（2026-11-03 早前会话），本轮不计入单题 |
| 计时 | 页面 `duration_ms`（点击开始 → 服务端收到结束） | 记录脚本：题面显示时刻 → 提交结束时刻 |

两者都不做延时注入、不刷新页面、不开多标签。

## 4. 分组与顺序

- G1（HCS）：`G1-T1` 可答 → `G1-T2` 无充分依据
- G2（DocFetcher）：`G2-T2` 无充分依据 → `G2-T1` 可答

组内顺序相反，用于抵消"总是先做可答题"的顺序效应。两组题的难度设计为同构：
每题都是单要素事实型（可答）或"部分相关但缺关键要素"（无充分依据）。

## 5. 计时口径

- 起点：题面第一次呈现给操作者的时刻。HCS 为点击"开始任务"后题面渲染；DocFetcher 为操作记录中写入题面并记 `shown_at` 的时刻。
- 终点：提交"找到 / 未找到 / 中止"并选定依据的时刻。
- 上限：单题 **300 秒**。超时记"未完成"，不记成功。
- 初始化、建索引、应用启动不计入单题用时。
- 本轮所有时长均为**同一 AI 代理在本机操作**的耗时，不是真人耗时。

## 6. 操作者

只有一个执行者：本会话的 AI 代理，用屏幕截图 + OCR 核对界面、用鼠标/键盘操作。
两个工具由同一代理先后操作，未做工具间交叉（同一题不跑两遍），因此不能排除学习效应。
**执行者同时是出题者，且此前参与过语料构建与 Eval30 标注，可能记得部分条款，本轮为非盲试跑，
不构成盲测。**

## 7. 记录内容

- HCS：`logs/ux_trial/runs/<run_id>/`（`run.json` + `events.jsonl`），含查询、结果证据、原文打开与确认、结束状态。
- DocFetcher：`logs/timing_trial/<session_id>/session.json` + `actions.jsonl` + 截图。
- 每题都记录：题面、工具、顺序、查询文本、打开的文件/条款、结束状态、所选依据、异常。

## 8. 评分（执行后按预先保存的参考依据）

| 判定 | 含义 |
| --- | --- |
| 充分 | 展示或选中证据包含参考条款，且可见文字覆盖回答所需全部要素 |
| 部分 | 只覆盖部分要素，或只到相近条款 |
| 不充分 | 未找到，或找到的条款不能回答 |
| 正确拒绝 | 无答案题以"未找到"结束，且未把相近条款当答案 |
| 误报答案 | 无答案题以"找到依据"结束，但证据不能回答 |
| 未完成 | 超过 300 秒 |

无答案题只判断"本次 A/B 资料范围内是否找到充分依据"，**不据此断言整个法规体系没有答案**。

## 9. 异常处理

- 卡住或中断：保留已写日志，标注 `invalid_reason`，不计入耗时汇总的"完成"项。
- 不为了让结果好看而重跑；若必须重跑，保留首次记录并注明原因。

## 10. 不修改的内容

模型、语料、排序参数、拒绝规则、题目与参考依据在执行后不再调整；
评分只读预先保存的参考依据，不根据试跑结果改题。
