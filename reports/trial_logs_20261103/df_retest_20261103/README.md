# DocFetcher 1.1.27 四题重测原始证据（2026-11-03）

本目录是 `logs/df_retest_20261103/` 的**脱敏证据子集**，供独立核对首次显示时间与整题用时。未上传全部连续帧、PDF 原文、法规全文、模型或旧实验结果。

## 1. 时间口径

- `enter_begin`：调用 `pyautogui.press("enter")` 之前记录；实际 keyDown 在其后约 10ms 内发生。
- `enter_end`：`press` 返回（keyUp 完成）后记录；本批按键跨度 102.8–105.9ms。
- 首帧可见区间统一写作 `[前一帧 t_end, 首帧 t_end]`；误差取区间宽度。
- 所有 `epoch_ms`、`at` 均为本机系统墙钟（+08:00），毫秒精度。

## 2. `frames.jsonl` 字段

- `seq`：从 0 开始的帧序号；`file`：对应 JPEG 文件名（保留原始帧号）。
- `t_start`：调用 `dlg.capture_as_image()` 之前的时刻。
- `t_end`：`capture_as_image()` 返回的时刻；首帧判定使用该时刻。
- `t_saved`：JPEG 写盘完成时刻，晚于 `t_end`。
- 本目录只上传每次搜索的首帧、前一帧、后一帧；`frames.jsonl` 仍是整段录制清单，未上传帧保留本机。

## 3. 首帧判定方法

- 只对结果行区域（窗口内 `x >= 230`, `y 82–170`）做 OCR，避免把左侧文件类型树、介绍页算入。
- Q1 重启后结果区为空，首帧判据为首次出现 `A_spec.pdf 915` / `B_copy_cas.pdf 504`。
- Q2–Q4 的文件名与上一题相同，判据为结果行分数变化：`915/504 → 911/466 → 658/553 → B503/A414 → B90`。
- 清空、搜索中、仅剩静态路径栏的帧不算结果首次显示。

## 4. 帧率与局限

- 目标 20fps；实测平均帧间隔 50.1–50.8ms，最大 178.6ms（Q1）。
- 窗口级像素捕获（`capture_as_image` + JPEG 序列），不是 GPU 合成事件级时间戳，也不是系统级视频编码文件。
- 因此首帧可见时刻只能给区间；Q1 区间宽度 197.2ms，其余 26.5–58.3ms。
